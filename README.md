# Discrete Full-Band Monte Carlo Algorithm for Electron Transport

**A simulation tool for high-field transport in 2D semiconductors.** By incorporating electronic band energies and electron-phonon coupling matrix elements from first-principles calculations, this code generates electron occupations, average velocities of electrons, and other high-field transport properties.

For more details, please refer to the [published paper](https://doi.org/10.1103/PhysRevB.102.115405).
